# Archived al-folio project examples

These are the complete project 1–9 source files as they stood before replacing the public examples with Campus Flow and Morning Paper.
Their contents are unchanged, including the Applied/Personal category values set earlier in this checkout.

They are retained as reference material, not active project pages. The entire `docs/` directory is excluded from Jekyll output.
The original image assets, bibliography entries, and gem-provided image components remain available in the repository.

See [the project guide](../PROJECTS.md) for a comparison of all nine examples, reusable image layouts, citations, comments, redirects, and instructions for adding a new project with the current site style.
